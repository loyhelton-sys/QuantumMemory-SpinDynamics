# QuantumMemory-SpinDynamics

GPU-accelerated Julia package for simulating spin ensemble dynamics and optical quantum memories.

## Features

- First-order Bloch dynamics
- Frequency inhomogeneity
- Coupling inhomogeneity
- Constant pulse
- Gaussian pulse
- WURST pulse
- Bloch sphere animation (Makie)

## Current Status

✅ Constant pulse validated

✅ Detuning dynamics validated

🚧 Cavity model under development
